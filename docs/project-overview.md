# Project Detail

## 프로젝트 주제

**왜 남고, 왜 떠나는가**  
2023년 5월 대량 유입 사용자의 잔존 행동 분석과 반복 이용 개선 전략

## 프로젝트 목적

첫 Vote 경험 자체는 빠르게 발생했지만 이후 Weekly Retention이 급격히 감소했습니다.  
이에 초기 사용자 행동을 강도와 지속성으로 나누고, 어떤 행동이 이후 잔존 차이를 더 잘 구분하는지 확인했습니다.

## 핵심 분석 흐름

1. 2023년 5월 Vote 관측 가능 사용자 정의
2. 48h Activation 기준 설정
3. Weekly Retention 감소 확인
4. 초기 강도 / 지속성 지표 설계
5. 4개 행동 세그먼트 구성
6. 세그먼트별 W2·W4 Retention 비교
7. 카이제곱 검정으로 지속성과 이후 Retention 간 연관성 확인
8. 첫 주 일별 참여율을 기반으로 R3 재참여 액션 근거 도출

## 담당 범위

- 현상 및 문제 정의
- 사용자 행동 / Retention 분석
- 초기 행동 지표 설계
- 세그먼트 분석
- 통계 검정
- R3 재참여 타겟·시점·액션 도출

A/B Test 상세 설계와 Question 분석은 팀 내 다른 담당자가 진행했습니다.

## 핵심 결과

- 48h Activation: **89.03%**
- Weekly Retention: W2 **68.0%** → W4 **24.9%** → W8 **2.8%**
- 같은 초기 강도에서 고지속 vs 저지속 W2 Retention 차이: **44.12%p**
- 같은 지속성에서 고강도 vs 저강도 W4 Retention 차이: **0.02%p**
- W2~W8에서 초기 지속성과 이후 Retention 간 **p < .05**
- 고강도 사용자의 R3 → R4 참여율: **-9.24%p**

## 분석에서 액션으로

저지속 여부는 R7 이후에야 확정할 수 있으므로, R3 시점에 사용할 수 있는 선행 행동을 기준으로 운영 타겟을 구성했습니다.

- WHO: 고강도 + R1 Vote 사용자 **2,743명**
- WHEN: 첫 Vote 기준 **R3**
- WHAT: Vote 화면 연결 **재참여 알림 1회**

이 액션의 실제 효과는 아직 검증되지 않았으며, 후속 A/B Test가 필요합니다.

## 해석 시 주의점

본 분석의 결과는 관찰 데이터에서 확인한 연관성입니다.  
따라서 “지속성이 Retention을 높였다”가 아니라  
**“지속성이 높은 사용자와 낮은 사용자 사이에서 이후 Retention 차이가 크게 나타났다”**고 해석합니다.
