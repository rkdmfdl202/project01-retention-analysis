# 왜 남고, 왜 떠나는가  
### 2023년 5월 대량 유입 사용자의 잔존 행동 분석과 반복 이용 개선 전략

> 6인 팀 프로젝트 중 **현상·문제 정의 → 사용자 행동·Retention 분석 → R3 재참여 타겟·시점·액션 도출**까지 제가 담당한 영역을 포트폴리오 목적으로 정리한 저장소입니다.  
> **A/B Test 상세 설계는 팀 내 별도 담당자가 수행했습니다.**

## 1. Project Overview

2023년 5월 신규 가입자가 크게 증가한 이후,  
단순히 첫 Vote를 경험한 사용자가 아니라 **어떤 사용자가 이후에도 반복적으로 남는지**를 분석했습니다.

초기 이용 행동을 **강도(Intensity)**와 **지속성(Persistence)**으로 나누고,  
각 행동 유형의 이후 Retention을 비교하여 재참여 전략의 근거를 도출했습니다.

### Main Question

**“첫 Vote 이후, 누가 남고 누가 멈췄는가?”**

## 3. Problem Definition

분석 대상은 2023년 5월 가입자 중 Vote 행동을 관측할 수 있는 10개 학교 사용자입니다.

| 항목 | 값 |
|---|---:|
| Vote 관측 가능 가입자 | 4,648명 |
| 48h Activation 사용자 | 4,138명 |
| 48h Activation Rate | **89.03%** |

48h Activation은 높았지만 Weekly Retention은 빠르게 감소했습니다.

- W1: 96.6%
- W2: 68.0%
- W3: 42.3%
- W4: 24.9%
- W5: 13.7%
- W6: 6.8%
- W7: 3.9%
- W8: **2.8%**

따라서 문제를 단순한 **“첫 Vote 진입”**이 아니라,

> **“첫 경험을 반복 이용으로 어떻게 연결할 것인가?”**

로 재정의했습니다.

---

## 4. Why 48h Activation?

Activation은 **가입 후 48시간 이내 첫 Valid Vote를 경험한 사용자**로 정의했습니다.

첫 Vote 누적 사용자를 비교했을 때:

| 기준 시점 | 누적 사용자 | 직전 구간 대비 증가 |
|---|---:|---:|
| 24h | 3,891명 | - |
| 48h | 4,138명 | **+247명** |
| 72h | 4,238명 | +100명 |
| 96h | 4,283명 | +45명 |

24h 이후에도 48h까지 의미 있는 추가 유입이 있었지만,  
48h 이후부터 증가폭이 크게 둔화되었습니다.

따라서 **초기 핵심 행동 진입을 충분히 포착하면서 이후 증가폭이 둔화되는 지점인 48h**를 Activation 기준으로 설정했습니다.

---

## 5. Analysis Design

### 5-1. 초기 강도 (Intensity)

첫 Valid Vote 이후 24시간 미만의 Valid Vote 수를 기준으로 분류했습니다.

- **고강도:** 30회 이상
- **저강도:** 30회 미만

### 5-2. 초기 지속성 (Persistence)

R0(첫 Valid Vote 당일)를 제외하고,  
**R1~R7 중 Valid Vote가 발생한 서로 다른 날짜 수**를 기준으로 분류했습니다.

- **고지속:** 5일 이상
- **저지속:** 5일 미만

> 30회 / 5일 기준은 “성공 사용자의 최적 기준”이 아니라  
> **행동량과 반복성을 비교하기 위한 분석용 분류 기준**입니다.

### 5-3. Retention

후속 Retention은 이후 주차의 Valid Vote 경험 여부를 기준으로 비교했습니다.

특히 W1은 지속성 정의 구간(R1~R7)과 겹치기 때문에,  
**독립적인 후속 비교는 W2 이후를 중심으로 해석했습니다.**

---

## 6. User Segmentation

48h Activation 사용자 4,138명을 초기 강도 × 초기 지속성으로 4개 그룹으로 구분했습니다.

| Segment | 사용자 수 | 비율 |
|---|---:|---:|
| 고강도 · 고지속 | 2,088명 | 50.46% |
| 고강도 · 저지속 | 673명 | 16.26% |
| 저강도 · 고지속 | 652명 | 15.76% |
| 저강도 · 저지속 | 725명 | 17.52% |

이 세그먼트는 잔존/이탈을 미리 판정하기 위한 분류가 아니라,  
**초기 행동 패턴과 이후 Retention의 차이를 비교하기 위한 분석 프레임**입니다.

---

## 7. Key Finding

### 같은 초기 강도에서: 지속성 차이는 크게 나타남

고강도 사용자끼리 비교했을 때 W2 Retention은:

- 고강도 · 고지속: **83.05%**
- 고강도 · 저지속: **38.93%**

→ **44.12%p 차이**

### 같은 지속성에서: 초기 강도 차이는 거의 없음

고지속 사용자끼리 비교했을 때 W4 Retention은:

- 고강도 · 고지속: **31.27%**
- 저강도 · 고지속: **31.29%**

→ **0.02%p 차이**

### Interpretation

> 초기 Vote 횟수 자체보다,  
> **여러 날 반복해서 Vote한 ‘지속성’에서 이후 Retention 격차가 더 크게 나타났습니다.**

단, 이는 관찰 데이터에서 확인한 **연관성**이며 인과관계를 의미하지 않습니다.

---

## 8. Statistical Validation

초기 지속성(고지속/저지속)과 각 주차 Retention(잔존/미잔존)이 모두 범주형 변수이므로  
**카이제곱 검정(Chi-square test)**을 사용했습니다.

| Week | 고지속 | 저지속 |
|---|---:|---:|
| W2 | 83.3% | 38.0% |
| W3 | 54.4% | 18.5% |
| W4 | 31.3% | 12.3% |
| W8 | 3.7% | 0.9% |

W2~W8 모든 주차에서 **p < .05**로,  
초기 지속성과 이후 Vote Retention 간 **통계적으로 유의한 연관성**을 확인했습니다.

---

## 9. From Insight to Action

분석 결과를 실제 재참여 액션으로 연결하기 위해 첫 주 일별 참여율을 확인했습니다.

고강도 사용자의 Vote 참여율:

- R1: 99.35%
- R2: 94.46%
- R3: 88.63%
- R4: 79.39%

특히 **R3 → R4에서 -9.24%p** 하락했습니다.

다만 “저지속 사용자”는 R7이 지나야 확정할 수 있으므로,  
R3 시점에는 실제로 식별 가능한 행동 기준이 필요했습니다.

### 제안한 운영 타겟

- **WHO:** 고강도 + R1 Vote 사용자 2,743명
- **WHEN:** 첫 Vote 기준 R3
- **WHAT:** Vote 화면으로 연결되는 재참여 알림 1회

이 분석을 기반으로 팀에서는 후속 A/B Test 설계를 진행했습니다.

> 실제 제품 효과는 아직 검증되지 않았으며,  
> 알림의 인과 효과는 실험을 통해 확인해야 합니다.
